# Space Zombies game

An Ursina-based 1-bit dithered FPS demo with animated sprites, pickups, interactable objects, and enemy/boss encounters.

## Requirements

- Python 3.11+
- `ursina`
- `pillow`

## Run

```bash
python test_environment.py
```

## Controls

- `WASD` move
- Mouse look
- `Space` jump
- `E` interact
- `T` toggle the dither shader
- `ESC` quit

## Project Files

- `test_environment.py` main game/demo entry point
- `retro_dither.py` helper/reference module
- `textures/` environment textures and sprites
- `Gun Sprites/` weapon art assets
- `Free Characters with Animations For FPS game/` enemy and boss frame animations
